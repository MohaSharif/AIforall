# OrganicBuilderCLI

تطبيق CLI تفاعلي بـ **Windows PowerShell 5.1+** لتدريب طلاب الصف الحادي عشر على المجموعات الوظيفية في الكيمياء العضوية (الفصل 2).

## المحتوى العلمي
يدعم التدريب على:
- هاليدات الألكيل (R–X)
- الكحولات (–OH)
- الألدهيدات (–CHO)
- الكيتونات (كربونيل داخلي)
- الأحماض الكربوكسيلية (–COOH)

## التشغيل
من داخل مجلد المشروع:

```powershell
powershell -ExecutionPolicy Bypass -File .\OrganicBuilder.ps1
```

## الملفات
- `OrganicBuilder.ps1`: التطبيق الرئيسي.
- `data/molecules.json`: قاعدة بيانات المركبات (80 مركبًا).
- `user/progress.json`: ملف التقدم والإحصاءات (يُنشأ تلقائيًا).

## ما الذي يحدث عند أول تشغيل؟
- يتم إنشاء المجلدات `data` و `user` تلقائيًا إذا كانت غير موجودة.
- يتم تحميل قاعدة البيانات من `data/molecules.json`.
- يتم إنشاء `user/progress.json` تلقائيًا إذا كان غير موجود.

## أوضاع التطبيق
1. **وضع التدريب السريع**: تحديد العائلة الوظيفية من الصيغة.
2. **Name-It**: اختيار اسم المركب من 4 خيارات.
3. **Properties Duel**: مقارنة خاصية بين مركبين.
4. **Build & Explain**: إدخال صيغة مكثفة والحصول على بطاقة تفسير.
5. **لوحة التقدم**: عرض الإحصاءات والأخطاء المتكررة.
6. **الإعدادات**: تعديل الصعوبة وعدد الأسئلة والمؤقت.

## استكشاف الأخطاء

### 1) مشكلة ExecutionPolicy
إذا ظهر خطأ متعلق بسياسة التنفيذ، شغّل الملف بنفس الأمر التالي:

```powershell
powershell -ExecutionPolicy Bypass -File .\OrganicBuilder.ps1
```

### 2) ترميز الأحرف العربية
التطبيق يضبط `OutputEncoding` إلى UTF-8 تلقائيًا. إذا ظهرت رموز غير مفهومة، استخدم Windows Terminal أو PowerShell حديث.

### 3) تلف ملف التقدم
إذا كان `user/progress.json` تالفًا، سيقوم التطبيق بإنشاء ملف جديد تلقائيًا.

## حفظ التقدم
يتم حفظ التقدم تلقائيًا:
- بعد كل وضع تدريب
- وعند الخروج من البرنامج

يشمل الحفظ:
- إجمالي الإجابات
- عدد الإجابات الصحيحة
- الدقة حسب الوضع والعائلة
- أكثر الأخطاء تكرارًا
- سلسلة النشاط اليومي
- الإعدادات
